# 项目开发约定

**开发期约定（上线前删除）：** 以当前需求为准，允许直接重构和破坏性变更，无需兼容旧版本。不要添加历史兼容层、旧逻辑兜底或双轨实现；修改时同步更新调用方并清理废弃代码。

## 项目规模与设计原则

- 本项目是由一个人开发和维护的小项目，以简单、清晰、易维护为优先，不要过度设计。

## 代码定位

- 需要查找或定位项目代码时，必须先查阅 `docs/FEATURE_CODE_MAP.md`，再根据其中的功能映射和检索锚点继续定位。

## Dart 异步编码规范

- 项目代码不使用 `unawaited(...)`。
- 需要等待完成、获取返回值或保证执行顺序时，使用 `await`。

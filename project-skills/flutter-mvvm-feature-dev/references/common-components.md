# 共用组件

## 放在哪里

- 只供一个页面使用：`pages/<feature>/widgets/`。
- 同一业务多个页面使用：业务目录的 `widgets/`。
- 跨业务使用，且不依赖业务模型：`lib/widgets/`。
- 颜色、字体、间距、圆角和 Theme 扩展：已有 theme 目录。

项目已有其他目录安排时，跟随项目，不为套模板搬目录。

## 什么时候提取

重复 UI 的用途和参数已经明确，或拆出组件能让职责、命名和测试更清楚时，再提取。不要为以后可能复用而增加大量可选参数。

## 组件接收什么

- 文案、图标、颜色、状态和简单展示数据。
- `VoidCallback`、`ValueChanged<T>` 等回调。

组件不直接依赖 AppContainer、业务 Service、具体 VM、AppPage、Navigator，或 Firebase、推送、埋点等服务。

业务动作留在 VM，组件只传出事件。文案继续走 l10n。

放入全局组件目录前，确认它确实跨页面复用、参数少且稳定，并使用已有主题和交互风格。
